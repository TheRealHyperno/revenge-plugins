# Revenge plugins

## MessageLogger
Keeps deleted messages in chat (highlighted red) and shows edit history, like Vencord's MessageLogger. The log is kept in memory only and clears when the app restarts.

Install in Revenge (Settings → Plugins → +):
`https://therealhyperno.github.io/revenge-plugins/modlog/`

## Development
    npm install
    npm run build   # outputs to dist/<plugin>/
Pushing to `main` builds and deploys to GitHub Pages automatically.
